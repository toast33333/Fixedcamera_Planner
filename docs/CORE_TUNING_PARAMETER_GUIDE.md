# `core_tuning.yaml` 参数逐项说明

本文对应配置文件：

```text
src/png_planner/config/core_tuning.yaml
```

说明基于 2026-11-13 当前代码，共覆盖配置文件中的 **134 个参数**。文中“当前值为什么这样设置”表示当前项目阶段采用这一数值的工程原因，不代表它已经在所有实机、载荷和速度下完成最终标定。

本次清理从统一调参文件中删除了3个实质冗余项：

- `max_target_vertical_speed_mps`：当前雷达估计器固定令目标 `vz=0`，该上限不会参与有效计算；
- `target_velocity_feedforward_gain_z`：其输入目标 `vz` 恒为0，改变增益不会改变指令；
- `camera_pitch_servo_pwm_us_per_deg`：旧版兼容斜率，已经由 `measured` 和 `datasheet` 两套具名斜率取代。

这些删除不改变当前运行结果。若以后加入靶机竖直速度估计，应同时重新设计竖直状态估计和前馈，而不是只把两个旧键加回来。

## 0. 使用前先理解三件事

1. `core_tuning.yaml` 是统一调参入口，会被视觉拦截节点、雷达抵近节点、舵机角度控制节点、角度到 PWM 映射节点及硬件适配节点分别读取。每个节点只使用自己认识的参数。
2. 配置文件中的速度和角速度上限只限制本算法发出的指令，不能替代 ArduPilot、MAVROS、飞控参数和飞机动力学本身的限制。
3. 某些启动脚本或 launch 文件会针对特定测试覆盖参数。外场确认最终生效值时，应查看节点启动日志，或使用 `rosparam get /fixed_camera_ibvs`、`rosparam get /radar_approach_handover`。

推荐的修改原则：一次只改一类参数；先改增益，再改上限；每次保留原值、试验工况、结果和回退值。

## 1. 视觉拦截性能与时间对齐

当前水平基础控制近似为：

```text
yaw_rate = sat(k_yaw * 水平LOS角误差
             + k_yaw_d * 水平LOS角速度
             + 水平视野保持附加项)
```

当前竖直基础控制近似为：

```text
vertical_acceleration = N_nav_z * 前飞速度 * 竖直LOS角速度
vertical_integral += vertical_acceleration * dt
vz = sat(k_z_ff * 竖直LOS角误差
       + vertical_integral
       + 竖直视野保持附加项)
```

| 参数（当前值） | 含义与当前设置理由 | 调整方向与注意事项 |
|---|---|---|
| `k_yaw: 1.5` | 水平LOS角误差到偏航角速度的比例增益。目标偏离期望水平方向时，它决定测试机多快转向。`1.5` 是此前仿真筛选后采用的中等强度基线。 | 调大：水平回正更快，但容易过冲、摆振并快速碰到 `max_yaw_rate`。调小：动作更平滑，但高速横向工况可能跟不上。优先在纯水平试验中调整。 |
| `k_yaw_d: 0.5` | 水平LOS方位角速度项的增益，用于根据目标视线正在怎样移动提前给出偏航响应。当前值提高了对快速横向运动的跟随能力。 | 调大：更重视LOS运动趋势，但视觉抖动和角速度估计噪声会更明显地进入指令。调小：指令更稳，但可能出现明显滞后。通常先调 `k_yaw`，再小步调它。 |
| `k_z_ff: 1.5` | 代码中实际是“竖直LOS仰角误差到竖直速度”的比例增益。虽然名称带 `ff`，当前实现不是单纯前馈。`1.5` 是竖直仿真调参后保留的基线。 | 调大：升降回正更积极，严苛高度差下更有利，但可能上下过冲并撞到 `max_vz`。调小：更平滑，但目标可能持续向画面上下边缘移动。 |
| `N_nav_z: 2.0` | 竖直PN项的导航系数，乘以“前飞速度 × LOS仰角速度”得到竖直加速度，再积分成竖直速度。`2.0` 是相对温和的起始值。 | 调大：对目标竖直运动和LOS变化更敏感，但会加快积分积累、增加噪声和饱和风险。调小：稳定但跟随变慢。应与 `k_z_ff` 分开调。 |
| `vertical_integrator_decay: 0.98` | 当竖直像素误差进入5 px死区时，每个控制周期把竖直积分项乘以0.98，避免旧积分长期残留。50 Hz下约1秒后保留36%。 | 调小：积分释放更快，减小回中后的残余升降，但持续扰动补偿会更弱。调大并接近1：记忆更久，可能造成过冲或慢性漂移。范围应保持0～1。 |
| `use_detection_header_stamp: true` | `true` 时使用 `/object_detections` 中图像采集时刻的 `header.stamp`，在IMU历史中找对应姿态。这是当前正式方案，避免人为猜测视觉延迟。 | 正常保持 `true`。只有确认相机时间戳无效、时钟不同步或消息未正确盖章时，才临时改为 `false` 启用固定延迟方案。切换后要重启拦截节点。 |
| `image_delay_sec: 0.08` | 仅在 `use_detection_header_stamp=false` 时生效，认为图像采集发生在检测消息到达控制器前0.08 s。它保留原来的外场应急估计。 | 如果固定延迟模式下补偿仍滞后，可根据实测端到端延迟修改；估得过大会使用过早姿态，估得过小会保留滞后。时间戳模式为 `true` 时改它没有作用。 |

## 2. 测试机动力学与指令上限

### 2.1 视觉拦截阶段

| 参数（当前值） | 含义与当前设置理由 | 调整方向与注意事项 |
|---|---|---|
| `min_forward_speed: 1.0` | 雷达交接节点向视觉节点发布建议前飞速度时，视觉节点允许的最小值。当前设1 m/s，避免动态速度建议被压到完全停止。 | 调大：始终保留更多前冲速度；调小：允许更慢的近距离测试。它主要限制动态速度话题，不会自动把所有 `V_default` 提高到该值。 |
| `max_forward_speed: 20.0` | 视觉拦截节点接受和发布的前飞速度上限。20 m/s是为5～15 m/s靶机保留追赶裕量的当前软件上限。 | 调大前必须确认飞机、飞控、场地和姿态能力；调小可降低首次外场风险。它不是飞控固件速度上限，也不保证飞机能达到该速度。 |
| `forward_speed_smoothing_alpha: 0.25` | 收到新的动态前飞速度建议时，按 `V←V+0.25(V_request−V)` 做一次一阶平滑，避免交接速度突跳。 | 调大：更快接近新速度，但突变更明显；调小：更平滑但响应慢。取值范围0～1，0会导致动态速度永不更新。 |
| `forward_speed_accel_limit_mps2: 1.5` | 视觉阶段前飞速度正向增加时的加速度限制，单位m/s²。当前1.5用于减少从悬停突然建立高速造成的大俯仰。代码允许减速立即生效。 | 调大：更快建立速度，但姿态冲击更大；调小：更安全平滑，但高速工况可能长时间追不上。0表示关闭正向加速度限制。 |
| `max_yaw_rate: 1.0` | 视觉阶段最终偏航角速度上限，单位rad/s，约57.3°/s；基础控制和视野保持相加后共同受它限制。 | 调大可提高急转跟踪能力，但可能超过飞控和机体可实现范围；调小更稳但容易横向丢目标。先确认指令是否经常饱和，再决定是否提高。 |
| `max_vz: 2.0` | 视觉阶段最终竖直速度指令上限，单位m/s；基础竖直控制与视野保持相加后共同受它限制。 | 调大只在指令经常达到±2 m/s时才有用，同时会增加高度变化和安全风险；若多数时间未饱和，提高它不会增强控制，应改增益。 |

|---|---|---|

| `max_handover_forward_speed_mps: 20.0` | 雷达节点向视觉节点推荐交接后前飞速度时的上限。推荐值为“估计靶机水平速度＋闭合裕量”，再夹在最小值和该上限之间。 | 调大只影响交接速度建议，仍受视觉 `max_forward_speed` 限制；两者应保持一致或前者不高于后者。当前都为20 m/s。 |

## 3. 雷达抵近、估计与交接

### 3.1 雷达周期与滤波

### 3.2 移动终端点抵近控制

雷达阶段的主要速度关系为：

```text
v_test = target_velocity_feedforward_gain * v_target
       + position_gain * (p_terminal - p_test)
```

| 参数（当前值） | 含义与当前设置理由 | 调整方向与注意事项 |
|---|---|---|
| `terminal_camera_range_m: 25.0` | 靶机到相机理想终端点的斜距。它用于连续生成移动吸引点，不是“到25 m这个单点才交接”。20°上抬时约对应测试机在靶机后23.49 m、下方8.55 m。 | 调大：更早、更远建立视觉几何，目标在图中通常更小；调小：更近、更激进，识别框更大但安全余量减少。需与10～30 m交接范围协调。 |
| `position_gain_xy: 0.40` | 水平位置误差到水平修正速度的比例增益，单位约1/s。当前值让抵近收敛不过分激进。 | 调大追移动终端点更快，但雷达噪声更容易变成速度变化；调小更平滑但位置误差收敛慢。 |
| `position_gain_z: 0.35` | 竖直位置误差到竖直速度的比例增益。当前略低于水平增益，减少雷达高度噪声造成的上下动作。 | 调大更快建立高度差；调小更平稳。最终仍受竖直速度和竖直加速度上限限制。 |
| `target_velocity_feedforward_gain_xy: 1.0` | 靶机估计水平速度的前馈比例。1.0表示先完整跟随靶机运动，再用位置反馈闭合终端点误差。 | 小于1会故意少跟随，位置反馈承担更多工作；大于1会超前追赶，可能增大闭合速度。通常以1为基线。 |
| `yaw_gain: 1.2` | 雷达阶段航向误差到偏航角速度的比例增益。当前让机头较快对准靶机运动方向/LOS融合方向。 | 调大对准更快但易摆动和碰到yaw rate上限；调小更平滑但交接前可能仍有较大航向误差。 |
| `use_braking_speed_profile: true` | 是否根据“距离终端点还剩多少水平误差”连续计算允许的修正速度。当前打开，避免只因进入某个固定距离就突然慢下来。 | 正式方案保持 `true`。改为 `false` 会退回旧的远近距离插值限速，此时 `near_position_correction_speed_mps` 重新成为关键参数。 |
| `approach_braking_deceleration_mps2: 2.0` | 制动曲线中的假定可用减速度：`v_limit=sqrt(2*a*max(error-buffer,0))`。当前2 m/s²用于生成连续速度包络。 | 调大：同样距离允许更高修正速度，相当于更晚、更强制动；调小：更早减速、更保守。它是规划参数，不代表飞机必然能实现该减速度。 |
| `approach_braking_position_buffer_m: 2.5` | 制动公式从水平误差中扣除的缓冲距离。误差接近2.5 m时，位置修正限速趋近0。 | 调大更早收掉修正、终端更平稳，但可能留下较大位置误差；调小允许追得更近，但交接前动作更大。 |

## 4. 视野保持

视野保持只在 `score>0.5` 且对应开关打开时产生附加项。它不再乘到基础拦截指令上，而是：

```text
最终yaw = 基础yaw + 水平视野保持附加yaw
最终vz  = 基础vz  + 竖直视野保持附加vz
```

中央不干预区域之外，单轴屏障形状为：

```text
a = sqrt(fov_guard_center_area_ratio)
r = abs(pixel_error) / image_half_extent
q = clip((r-a)/(1-a), 0, 0.999)
shape = min(q^2/(1-q^2), fov_guard_shape_max)
```

| 参数（当前值） | 含义与当前设置理由 | 调整方向与注意事项 |
|---|---|---|
| `enable_fov_guard: true` | 视野保持总开关。当前所有水平、竖直和三维拦截测试都希望保留该保护，所以打开。 | 关闭后基础拦截仍工作，舵机跟踪也不会被冻结，只是不再生成飞机yaw/vz视野附加量。用于隔离基础控制问题时可临时关闭。 |
| `fov_guard_min_detection_score: 0.50` | 只有检测 `score` **严格大于**0.5时，检测框才允许触发视野保持。它不再限制舵机正常跟踪和基础拦截。 | 调高减少低置信框误导飞机，但目标模糊时保护可能不启动；调低更灵敏但假框风险增大。 |

### 6.2 视觉舵机角度控制器

舵机角速度控制公式为：

```text
servo_rate = sat(Kp*error + Ki*integral(error) + Kd*d(error)/dt,
                 -max_rate, +max_rate)
command_angle += servo_rate * dt
```

| 参数（当前值） | 含义与当前设置理由 | 调整方向与注意事项 |
|---|---|---|
| `camera_pitch_servo_neutral_deg: 0.0` | 舵机机械中位在ROS相对角定义中的角度。当前以中位为0°，正角上抬、负角下压。 | 若机械安装零位有偏差，优先机械调整或明确标定后修改；该值也参与PWM相对角计算。 |
| `camera_pitch_servo_min_deg: -25.0` | 飞行控制器正常工作时允许的最小相对角，下压25°。这是飞行范围，不是PWM映射的全部标定范围。 | 首次实物应先缩到约−5°；确认机械净空后逐步放宽。绝不能超过机构硬限位。 |
| `camera_pitch_servo_max_deg: 25.0` | 飞行控制器正常工作时允许的最大相对角，上抬25°。 | 同上。若目标经常要求超过限位，应先检查安装角、飞机竖直控制和试验几何，而不是直接无限放宽。 |
| `camera_pitch_servo_kp_per_sec: 3.0` | 舵机角误差到舵机角速度的比例增益，单位约1/s。1°误差产生约3°/s比例速度，之后还受总限速。 | 调大回正更快但画面和舵机可能振荡；调小更稳但跟随慢。先在不上桨地面目标移动试验中调。 |

| `camera_pitch_servo_derivative_alpha: 0.2` | 导数低通中“本次原始导数”的权重：`D=0.2*D_raw+0.8*D_old`。当前偏平滑。 | 调大更快响应新变化但更噪；调小更平滑但导数滞后。范围0～1。 |
| `camera_pitch_servo_integral_decay: 0.98` | 误差进入死区或角度碰到限位时，每周期把积分乘0.98，释放积累。 | 调小释放更快；调大保留更久。当前Ki=0时主要是为以后启用积分预留。 |

| `camera_pitch_servo_axis_mount_y: 1.0` | 转轴方向的y分量（向左）。`[0,1,0]` 表示标准左右横向俯仰轴，符合当前安装假设。 | 若实际轴倾斜，连同x/z一起修改。把整个向量反号会改变有符号角误差方向，必须验证舵机动作符号。 |
| `camera_pitch_servo_axis_mount_z: 0.0` | 转轴方向的z分量（向上）。当前假设无竖直倾斜。 | 按真实铰链轴修正；三个值全为0时代码会告警并退回 `[0,1,0]`。 |

### 6.3 角度到PWM映射层

当前映射关系：

```text
P_us = neutral_us + selected_us_per_deg * (angle_deg - neutral_deg)
```

若 `camera_pitch_servo_pwm_reverse=true`，括号中的相对角先取反。

## 7. 推荐调参顺序

### 7.1 纯水平拦截

1. 固定 `k_z_ff`、`N_nav_z`，关闭竖直飞机控制和舵机动作。
2. 先调 `k_yaw`，观察水平误差收敛和过冲。
3. 再调 `k_yaw_d`，处理快速横向运动的滞后与摆动。
4. 只有确认基础控制稳定后，再调 `fov_guard_yaw_gain_radps` 和 `fov_guard_shape_max`。
5. 如果yaw长期顶到 `max_yaw_rate`，先确认是增益不足还是上限不足，不能只盲目加大增益。

### 7.2 纯竖直拦截

1. 先调 `k_z_ff`，让静态高度差能收敛。
2. 再调 `N_nav_z`，改善靶机竖直运动或LOS仰角快速变化时的响应。
3. 观察 `max_vz` 是否长期饱和；不饱和时提高上限没有作用。
4. 再调 `fov_guard_vertical_gain_mps`。
5. 舵机加入后，先保持 `Ki=0`，只调 `Kp`、死区和两级转速上限。

### 7.3 三维拦截

1. 使用已经分别稳定的水平、竖直参数组合。
2. 检查同时动作时是否经常触发总yaw/vz限幅。
3. 检查相机安装角、舵机轴向和IMU时间对齐，不要用控制增益补偿几何错误。
4. 最后再决定是否启用前飞速度缩放；当前 `fov_min_forward_speed_ratio=1.0` 表示不减速。

### 7.4 雷达抵近与交接

1. 先验证雷达时间戳、周期、位置误差和离群点，再调滤波参数。
2. 先调移动终端点位置增益和制动曲线，再调交接门限。
3. 交接失败时按日志分别判断：视觉连续帧、雷达速度方差、雷达年龄、距离、yaw rate、闭合速度、倾角、加速度、稳定持续时间，不能一次放宽全部门限。
4. 雷达舵机辅助最后开启；它不是完成雷达抵近和视觉交接的前置条件。
